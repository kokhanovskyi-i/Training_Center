Training Center
===============

Training Center is an educational Odoo module for managing a small training
center.

The module allows users to manage students, teachers, teacher categories,
subjects, lessons, teacher assignment history, reports, access rights,
translations, and automated tests.

Features
--------

* Manage students with personal, contact, and contract information.
* Manage teachers with specialties, categories, mentors, and assistants.
* Manage teacher categories.
* Manage a hierarchical subject classifier.
* Manage lessons between students and teachers.
* Track lesson statuses: planned, done, and cancelled.
* Track main teacher assignment history.
* Generate lesson reports using a wizard.
* Generate a printable teacher report in PDF format.
* Use kanban, search, pivot, graph, calendar, list, and form views.
* Use dedicated Training Center User and Admin security groups.
* Provide Ukrainian translation.
* Include automated tests.

Security Groups
---------------

The module provides two user groups:

* User
* Admin

The Admin group includes the User group.

Users can work with training center records, but cannot delete main records.
Admins can manage all module records, including deletion.
