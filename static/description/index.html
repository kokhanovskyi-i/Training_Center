Training Center

Training Center is an educational Odoo module for managing students, teachers, subjects, lessons, teacher assignment history, and reports.

Main Features

  • Student management with personal, contact, and contract information.
  • Teacher management with categories, specialties, mentors, and assistants.
  • Subject classifier with hierarchical subject structure.
  • Lesson management with planned, done, and cancelled statuses.
  • Main teacher assignment history.
  • Lesson and subject report wizards.
  • Printable teacher PDF report.
  • Teacher kanban view.
  • Dedicated User and Admin security groups.
  • Ukrainian translation.
  • Automated model tests.

Security Roles

The module includes two security groups: User and Admin. Admin inherits User rights.

Reports

Training Center provides analytical wizards and a printable teacher report with lesson history and student information.
