HR Hospital

HR Hospital is an educational Odoo module for managing patients, doctors, diseases, appointments, doctor assignment history, and hospital reports.

Main Features

  • Patient management with personal, contact, and medical information.
  • Doctor management with categories, specialties, mentors, and interns.
  • Disease classifier with hierarchical disease structure.
  • Appointment management with planned, done, and cancelled statuses.
  • Personal doctor assignment history.
  • Visit and disease report wizards.
  • Printable doctor PDF report.
  • Doctor kanban view.
  • Dedicated security groups and access rules.
  • Ukrainian translation.
  • Automated model tests.

Security Roles

The module includes role-based access control for patients, interns, doctors, managers, and administrators.

Reports

HR Hospital provides analytical wizards and a printable doctor report with visit history and patient information.
